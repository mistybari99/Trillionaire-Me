Goal Set Method

A SMART funnel. A broad aim passes through five tests and narrows into a goal that can be acted on.

S
Specific
What exactly will be achieved, and by whom?
Replace "get fit" with "run 5 km without stopping."
M
Measurable
How will progress and completion be counted?
Track distance logged each week.
A
Achievable
Is it realistic with the time and resources available?
Three 20-minute runs per week fit the schedule.
R
Relevant
Does it matter to the larger aim?
Supports the goal of better health.
T
Time-bound
By when will it be done?
Reach 5 km by 31 March.
Output
Committed SMART goal
Run 5 km without stopping, tracked weekly, by 31 March.
