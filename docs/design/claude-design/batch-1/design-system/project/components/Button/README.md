Full-width square button for the one main action per screen.

Use `.cta` for the primary action (`primary` fill, `on-primary` text, 52px high) and `.btn.ghost` for secondary actions (transparent, 1.5px `ink` border). One primary per screen; secondary actions sit in a two-column grid, the last one full width. The consumer supplies the label (Bangla first). Never round the corners. Focus ring: 3px `ember`, offset 2px. Static rendition; source: `.cta`, `.btn` in `src/ui/styles.css`.
