Small outlined label for status, DEMO and privacy markers.

Use `.tag` (neutral), `.tag.ok` (moss, done), `.tag.warn` (demo, needs care), `.tag.off` (muted). `.badge` is the DEMO banner on `demo-bg`; `.chip` is a quiet inline label. Colour is never the only signal: always include a word. Static rendition; source: `.tag`, `.chip`, `.badge`.
