# Field rules — short, specific, never confusing (owner request, 24 Oct 2026)

1. **One field = one fact.** Never "describe your situation". Each field asks for one thing.
2. **Prefer taps over typing:** choice chips → number → date → yes/no/unknown → one short word. Free text is the last resort.
3. **Short text ≤ 80 characters** (enforced in the form). Only note/entry/evidence fields allow 200.
4. **Every field shows what / why / example / format** (the "Help" under each field) — the user never has to guess what to write.
5. **"Don't know / Later / Not applicable / Prefer not" is always there** for numbers and choices (Unknown ≠ 0).
6. **Extra, optional:** a free "note or decision" box (Quick capture). The app finds amounts, percents, durations, dates and decisions with simple rules (no AI), shows them as tick-boxes the user can edit, and saves **only what is confirmed**. The original note stays on the phone. Reports are built from the confirmed items, not from raw text.
7. **Low-confidence guesses are flagged** ("please check"), start unticked, and a bare number is never assumed to be money.
8. **Later (G6, owner-approved cost):** AI may improve the finding step; the confirm step stays.
