# Bangla loanword swaps (owner rule, 1 Nov 2026)

> Updated 3 Nov 2026: the binding spelling guide is now `bangla-plain-final-decision.md`. Where this file differs (গোল replaces লক্ষ্য, ডাটা replaces ডেটা, "Demo" is written ডেমো, "রিয়েল" is আসল), the final decision wins. The table below is kept as history.

Rule: in Bangla and Mix text, a common everyday word that people already say in English is written as the English word in Bangla script (for example স্টাফ, not কর্মী). In Mix mode the English word is kept as English (Staff). Deen terms and plain Bangla words people really say stay Bangla. Latin digits stay. Bangla text is still unreviewed until TM-TST-161.

Applied with a one-time script over every Bangla string in the app. Total: **1088 word swaps** in **25 files**.

## Where it was applied

- UI text: `src/i18n/packs.ts` (Bangla pack, 648 swaps), `src/ui/prayerAlerts.ts`, `src/core/notify.ts`, `src/core/rules.ts`, `src/core/stages.ts`, `src/core/stageTemplates.ts`, `src/demo/seed.ts`.
- In-app glossary: `src/catalog/glossary.ts` (term names now use the common word; the meaning lines are plain Bangla).
- Forms and help: `src/catalog/fields.ts`, `src/schema/entities.ts`, `src/modules/capability.ts`.
- Library and content: `src/library/*`, `src/library/systems/*.json`, `public/content/pack-001.json` to `pack-008.json`.
- Mix mode: `MIX_TERMS` in `src/i18n/packs.ts` lists every loanword with its English form. Mix derives from the Bangla pack, so it keeps the English word automatically (a Bangla suffix is kept after a hyphen, for example Plan-এর).
- Not touched on purpose: `src/core/capture.ts` and `src/core/safety.ts` (they match Bangla words typed by the user), `src/i18n/registry.ts`, `src/ui/langMenu.ts`, `src/adapters/wikipedia.ts`. `index.html` and the manifest have no Bangla text. Docs outside the app (Spec, Register, DECISIONS_LOG, tests) keep their old wording as history.

## Words deliberately kept in Bangla

- Deen words: নামাজ, রোজা, যাকাত, সদকা, ফিতরা, কুরবানি, হজ, উমরাহ, হালাল, সুদ (রিবা), আখিরাত, ইবাদত, ওয়াক্তের নাম, আজান, দ্বীন.
- Everyday words people really say: দিন, টাকা, খরচ, হিসাব, কাজ, সপ্তাহ, মাস, সময়, ফোন, ব্যবসা, লাভ, বেতন, কিস্তি, পরিবার, স্বাস্থ্য, ঘুম, বিশ্রাম.
- লক্ষ্য: kept. Everyone understands it, "গোল" is not clearly more common, and it also means a football goal. Mix mode still shows Goal.
- যাত্রা (Journey), ডায়েরি, ধাপ for a small step (Mix shows Step), আসল (real), যোগ করুন, শুরু, শেষ, খুলুন, বন্ধ, চালু.
- সম্পদ and দায় (asset, liability), সিদ্ধান্ত, পরামর্শ, অনুমোদন, সম্মতি, নিরাপত্তা, অভ্যাস, মাপকাঠি, উদ্যোগ, ক্ষেত্র, দল, স্তর, পূর্বাভাস: plain Bangla that people use daily, or the English word would be less clear.
- কর্মী, কর্মচারী: no such word is in the app today. If staff text is added, write স্টাফ (the rule is in `MIX_TERMS`, so Mix shows Staff).
- যাচাই হয়নি: fixed wording for unreviewed Bangla, unchanged.

## How to add a new Bangla string

Use the loanword from the table above. If a new common English word is needed, add it to `MIX_TERMS` with its English form so Mix shows the English word.
